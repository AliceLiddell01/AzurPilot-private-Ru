# Маркер незавершённой публикации

Перед push или изменением PR атомарно запиши UTF-8 JSON в
`.codex/local/git-publication.json` обычным файловым инструментом. Убедись, что
родительские каталоги и файл не являются symlink/junction. Одна рабочая копия
допускает одну публикацию одновременно; существующий маркер сначала требует
проверки удалённого результата.

Все поля обязательны, другие запрещены; размер не превышает 4096 байт:

```json
{
  "workflow": "azurpilot-git-workflow",
  "repository_root_identity": "<sha256>",
  "operation": "push",
  "head_sha": "<exact-head-sha>"
}
```

`repository_root_identity` — SHA-256 от UTF-8 строки
`os.path.normcase(str(Path(root).resolve()))`, как в Stop hook.
`operation`: `push`, `pr-create`, `pr-edit`, `pr-ready`, `pr-draft`, `pr-merge`.
Маркер содержит только идентичность рабочей копии, операцию и ожидаемый HEAD.
Описание PR, секреты, URL с учётными данными и диагностика в него не входят.
Факты repository/base/head/PR остаются в текущей работе и локальном описании;
после прерывания их снова устанавливают чтением Git и GitHub.

Перечитай маркер перед внешней операцией. Сразу после неё проверь удалённое
постусловие. Только доказанный успех либо доказанное отсутствие изменения
позволяет удалить собственный маркер. Изменённое дерево, неопубликованные
коммиты и обычный Draft PR маркера не требуют. Срока истечения нет: возраст
не доказывает завершение сетевой операции.

При неизвестном результате:

- Push: `git ls-remote --refs` для точной ветки и репозитория, сравнение с
  ожидаемым HEAD. При другом SHA получи историю и проверь доставку ожидаемого
  коммита. Не перезаписывай новые удалённые коммиты. Повтор разрешён только
  после доказанного отсутствия доставки и новой предварительной проверки.
- Создание PR: поиск по repository/base/head; ровно один правильный PR с
  совпавшими описанием и Draft подтверждает успех. Не создавай дубль.
- Редактирование: полное чтение PR и сравнение title/body с локальным файлом.
  При расхождении или неполном чтении сохрани файл до разрешения проблемы.
- Ready/Draft/merge: чтение статуса и точного HEAD PR; для merge также merge SHA.
  Один exit code не подтверждает удалённый результат.

Если отсутствие изменения доказано, сними маркер и сообщи реальное препятствие,
которое нельзя устранить в пределах задачи. При неоднозначности сохрани маркер
и описание, продолжай ограниченную проверку только чтением. Stop hook один раз
просит продолжить работу; удаление маркера без свидетельств не является обходом.
