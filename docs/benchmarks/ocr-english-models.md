# Сравнительный benchmark английских OCR-моделей

Персональная версия AzurPilot работает только с международным сервером
**EN/Global**. Отдельные китайские, японские и традиционно-китайские OCR-веса,
словари и тестовые наборы удалены. Параметры выбора этих моделей были удалены
в product-контуре.

## Что сравнивается

На одном и том же наборе `sets_num` последовательно запускаются:

- `alocr_en_900k`;
- `azur_lane_v6_6`;
- `azur_lane_v6_5`;
- `ppocr_v6`;
- `alocr_en_v2_6`;
- `alocr_en_v2_0`;
- `alocr_en_v1_0`;
- `ncnn_azur_lane`, если английские NCNN-веса установлены.

`auto` — это режим выбора версии, а не отдельная модель.

## Граница измерения

Benchmark проверяет распознавание уже вырезанных строк. Он не измеряет:

- поиск текста на полном игровом экране;
- качество детектора `PP-OCRv6_tiny_det`;
- анимации и переходные кадры;
- все возможные надписи вне набора `sets_num`.

Результаты проходят через тот же `normalize_ocr_text("azur_lane", ...)`, который
использует production-контур в product-контуре. Поэтому сравнивается итоговая строка,
а не ненормализованный промежуточный вывод модели.

## Запуск

```powershell
uv run python -m tools.benchmarks.ocr_english_models --profile alas
```

Временно задать устройство ONNX-моделей:

```powershell
uv run python -m tools.benchmarks.ocr_english_models --profile alas --device gpu
```

Настройки профиля на диске команда не изменяет. Vendor Execution Providers во
время benchmark отключены, чтобы прогон не скачивал дополнительные runtime-пакеты
и оставался воспроизводимым.

## Вывод

Для каждой модели показываются:

- конкретная версия и файлы весов;
- backend;
- фактический runtime/provider;
- точность и число ошибок;
- средняя задержка и p95;
- понятный статус;
- место в рейтинге и рекомендация.

Рейтинг сначала учитывает точность. Более быстрая модель с ошибками не может
обойти модель с точностью 100%. При равной точности учитываются p95, средняя
задержка и время загрузки.

Полный машинно-читаемый результат сохраняется в:

```text
artifacts/ocr/english-model-benchmark.json
```

В JSON также записываются сведения о платформе, Python, OpenCV, runtime-ошибки и
до десяти примеров несовпадений для каждой модели.

## Статусы

- `ИДЕАЛЬНО` — 100% на текущем наборе;
- `ХОРОШО` — от 99% до 100%;
- `РИСК` — от 95% до 99%;
- `НЕ ПОДХОДИТ` — ниже 95%;
- `НЕ УСТАНОВЛЕНА` — отсутствуют веса или словарь;
- `ОШИБКА` — модель не удалось загрузить или выполнить.

Статус относится только к набору `sets_num` и не является абсолютной оценкой
модели на всех экранах игры.
