# Глоссарий

## Основные понятия

**AzurPilotRu**  
Персональная русскоязычная версия AzurPilot из ветки `personal/stable`.

**AzurPilot**  
Текущий продуктовый проект и форк, на котором основана эта версия.

**ALAS / AzurLaneAutoScript**  
Историческая база проекта. Имя `Alas` всё ещё встречается в классах, конфигурации, логах и task identifiers.

**Global / EN**  
Единственный поддерживаемый игровой регион текущей персональной версии.

**instance / профиль**  
Именованный пользовательский config и связанный runtime context. В пользовательской документации обычно используется слово «профиль».

**task / задача**  
Верхнеуровневая команда планировщика: например `Main`, `Commission` или `OpsiDaily`.

**group / группа**  
Группа параметров внутри задачи: `Scheduler`, `Fleet`, `StopCondition`.

**argument / параметр**  
Конкретное значение внутри группы: например `OilLimit`.

## Автоматизация

**Scheduler / планировщик**  
Система, которая определяет готовые задачи, приоритет и время следующего запуска.

**NextRun**  
Время, после которого задача снова может быть выбрана планировщиком.

**takeover**  
Состояние, когда автоматизация останавливается и требуется вмешательство человека.

**recoverable**  
Ошибка/состояние, после которого верхний уровень может безопасно продолжить или повторить работу.

**state loop**  
Основной цикл управления игрой:

```text
снимок экрана → распознавание → одно действие → новый снимок
```

## Распознавание UI

**Button**  
Объект распознавания интерфейса с областью поиска/клика.

**Template**  
Шаблонное изображение для matching.

**Page**  
Узел графа игровых экранов.

**OCR**  
Распознавание текста на изображении игры.

## Игровые понятия

**Operation Siren / OpSi / Операция «Сирена»**  
Большой отдельный режим Azur Lane со своими AP, валютами, зонами и задачами.

**AP / Action Point**  
Очки действия Operation Siren.

**PT**  
Очки/валюта события, если конкретное событие использует этот ресурс.

**morale / emotion / настроение**  
Игровая механика настроения кораблей, которую AzurPilotRu может учитывать при фарме.

## Эксплуатация

**`azur`**  
Repository-owned Python CLI для Build/Start/Stop/Repair/Update и operator tooling.

**Build**  
Подготовка project environment без Git update.

**Doctor**  
Read-only диагностика возможностей.

**Repair**  
Транзакционное восстановление окружения.

**Update**  
Контролируемое обновление пользовательской установки.

**tooling**  
Типизированная операционная infrastructure в `azurpilot.tooling`, не игровой слой.

## Ветки

**`personal/stable`**  
Стабильная пользовательская ветка AzurPilotRu.

**`master`**  
Чистое зеркало upstream master.

**upstream**  
Исходный `wess09/AzurPilot`.

## Developer-термины

**MCP**  
Model Context Protocol. В проекте есть first-party Dev MCP и Game MCP.

**integration**  
Внешняя developer capability через `azurpilot.integrations`.

**smoke test**  
Короткая сквозная проверка базового сценария.

**secret scan**  
Проверка diff/данных на случайно добавленные tokens, credentials и персональные данные.

**generated file**  
Файл, создаваемый генератором из source YAML/schema/metadata.
