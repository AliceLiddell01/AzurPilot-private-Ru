# Подключение Azur Lane

AzurPilotRu управляет игрой через Android runtime. Для первого запуска проще всего использовать проверенный сценарий **Windows + MuMu + Azur Lane Global**.

## Перед подключением

1. Запустите MuMu.
2. Запустите Azur Lane вручную.
3. Убедитесь, что установлена именно Global-версия.
4. Дождитесь загрузки игры до обычного интерфейса.
5. Не запускайте одновременно несколько одинаковых экземпляров эмулятора, если ещё не знаете, какой ADB serial должен использовать профиль.

## ADB

На Windows `azur build` проверяет проектный ADB и при необходимости устанавливает закреплённую версию в окружение проекта. Пользователю обычно не нужно вручную подменять `adb.exe` или копировать его в системные каталоги.

Если подключение не работает, сначала используйте штатную диагностику, а не случайный ADB из другой установки.

## Настройка устройства

В конфигурации AzurPilotRu основной параметр устройства — serial.

Значение по умолчанию:

```text
Serial: auto
```

Для первого подключения оставьте `auto`. В этом режиме проект пытается определить подходящее устройство штатным способом.

Игровой package в текущей версии фиксирован:

```text
com.YoStarEN.AzurLane
```

Он соответствует Global-клиенту. Подмена package на CN/JP/TW не является способом включить поддержку другого региона.

## Методы снимка и управления

AzurPilotRu поддерживает несколько backend-методов получения изображения и ввода. В конфигурации присутствуют, например:

- снимок: `auto`, `ADB`, `uiautomator2`, `aScreenCap`, `DroidCast`, `nemu_ipc` и другие;
- управление: `ADB`, `uiautomator2`, `minitouch`, `Hermit`, `MaaTouch`.

Новому пользователю не следует выбирать backend только по названию. Начните со штатных значений (`ScreenshotMethod: auto`, `ControlMethod: MaaTouch`) и меняйте их только при конкретной проблеме.

## Как понять, что подключение готово

Перед первой автоматизацией должны выполняться три условия:

- AzurPilotRu видит нужный Android runtime;
- package определяется как `com.YoStarEN.AzurLane`;
- проект может получать изображение игры и отправлять допустимые команды управления.

Если `Serial: auto` выбирает не то устройство или устройство не находится, не переходите сразу к боевым задачам. Сначала зафиксируйте фактический serial и используйте раздел [Решение проблем](../maintenance/troubleshooting.md).
