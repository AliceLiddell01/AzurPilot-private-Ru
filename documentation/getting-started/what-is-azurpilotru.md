# Что такое AzurPilotRu

AzurPilotRu — приложение для автоматизации повторяющихся действий в **Azur Lane Global**. Оно не модифицирует игровой клиент: программа наблюдает за интерфейсом игры через снимки экрана, распознаёт нужные элементы и взаимодействует с Android-устройством или эмулятором через поддерживаемые методы управления.

Для пользователя это выглядит так:

1. Azur Lane запущена в эмуляторе или на Android-устройстве.
2. AzurPilotRu подключается к этому устройству.
3. Вы настраиваете задачи через WebUI.
4. Планировщик решает, какая задача должна выполняться сейчас.
5. AzurPilotRu распознаёт текущее состояние игры и выполняет необходимые действия.
6. После завершения задача назначает следующий запуск или передаёт управление другой задаче.

## Что можно автоматизировать

Проект содержит несколько крупных групп задач:

- **Порт** — общие настройки, перезапуск и вспомогательные функции;
- **Боевой выход** — основная кампания и связанные сценарии фарма;
- **События** — событийные карты, рейды, коалиции и другие поддерживаемые режимы;
- **Автосбор наград** — комиссии, исследования, общежитие, гильдия и другие регулярные действия;
- **Ежедневные задания** — ежедневные миссии, сложный режим, учения, магазины и другие периодические задачи;
- **Операция «Сирена»** — отдельный набор задач для Operation Siren;
- **План острова** — поддерживаемые активности острова;
- **Инструменты** — дополнительные пользовательские функции.

Полный список постепенно собирается в разделе [Задачи автоматизации](../automation/README.md).

## Что AzurPilotRu не делает

AzurPilotRu не является отдельным клиентом Azur Lane и не заменяет саму игру. Для работы нужен доступный Android runtime с установленной Azur Lane.

Проект также не обещает одинаковую поддержку всех региональных версий игры. Текущая продуктовая граница фиксирована:

- сервер: `en`;
- Android package: `com.YoStarEN.AzurLane`;
- игровые ресурсы: `assets/en`;
- язык WebUI: `ru-RU`.

Другие package/server значения отклоняются до выполнения игровых действий.

## Чем эта версия отличается от исходного проекта

Персональная версия сохраняет игровую автоматизацию AzurPilot, но меняет эксплуатационный контур. В частности:

- активный пользовательский интерфейс русифицирован;
- запуск, остановка, обновление и восстановление вынесены в отдельные команды `azur`;
- обычный запуск не выполняет Git update;
- обновление ограничено контролируемым fast-forward сценарием;
- часть унаследованной телеметрии и project-controlled сетевых механизмов удалена;
- локальная инфраструктура PostgreSQL, Redis и observability управляется отдельным Docker Compose-контуром;
- добавлены собственные Dev/Game MCP и инструменты диагностики.

Для обычного пользователя важен не внутренний код этих компонентов, а их назначение. Поэтому эта Wiki описывает **как пользоваться системой и чего от неё ожидать**, а архитектурные детали вынесены в отдельный раздел.

## Насколько автоматизация безопасна

Автоматизация выполняет реальные действия в игре. Некоторые задачи могут расходовать нефть, монеты, попытки, очки действия или другие игровые ресурсы. Отдельные функции могут покупать предметы, запускать бои или изменять состояние аккаунта в рамках обычного игрового интерфейса.

Поэтому перед включением незнакомой задачи:

1. прочитайте её описание;
2. проверьте ограничения и условия остановки;
3. убедитесь, что выбран правильный профиль и устройство;
4. для первого запуска используйте понятный и ограниченный сценарий;
5. не оставляйте новую конфигурацию без наблюдения, пока не убедитесь, что она работает ожидаемо.

Следующий шаг: [Требования](requirements.md).
