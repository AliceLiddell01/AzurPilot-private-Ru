# План острова

Раздел **«План острова»** автоматизирует поддерживаемые активности острова.

Эта часть проекта развивается отдельно от классических кампаний и содержит функции с более узкими требованиями к управлению.

## Общие настройки

`IslandPlan` содержит глобальные настройки плана острова, включая параметры сезона.

## Предприятия

`IslandBusiness` управляет пятью предприятиями:

- рыбный ресторан;
- «Белый медведь»;
- гриль;
- закусочная Juu;
- кофейня Juu.

В task contract у каждого предприятия есть собственные группы настройки магазина/поведения.

## Ферма и ресурсы

Доступны:

- `IslandFarm` — ферма и сад/питомник;
- `IslandRancher` — ранчо и рыбное хозяйство;
- `IslandMineForest` — шахта и лес;
- `IslandManufacture` — производство;
- `IslandDailyGather` — ежедневный сбор ресурсов.

## Предприятия питания

Отдельные scheduler-задачи:

- `IslandRestaurant`;
- `IslandTeahouse`;
- `IslandGrill`;
- `IslandJuuEatery`;
- `IslandJuuCoffee`.

Для части этих задач локализация описывает последовательное приготовление блюд по требованиям меню.

## Ежедневные операции

- `IslandAirDrop` — ежедневное снабжение;
- `IslandCargoPreparation` — грузовые комиссии;
- `IslandDailyOrder` — ежедневные заказы;
- `IslandDailyInteract` — ежедневные/еженедельные взаимодействия;
- `IslandPearlSell` — торговля жемчугом.

## Ограничения методов управления

Текущая русская локализация прямо отмечает:

- `IslandAirDrop` — только `minitouch`;
- `IslandDailyInteract` — только `minitouch`;
- `IslandPearlSell` — только `minitouch`.

Для `IslandDailyInteract` также требуется наличие соответствующих assets кнопок.

`IslandDailyOrder` поддерживает не все типы заказов: локализация перечисляет срочные, испытания и лёгкие, а стандартные заказы помечает как неподдерживаемые.

## Торговля жемчугом

Локализация `IslandPearlSell` указывает расписание обработки: каждый вторник в 01:00.

## Рекомендация

Островные задачи лучше вводить по одной. Не включайте весь раздел одновременно, особенно если меняли ControlMethod или используете новый набор assets.
