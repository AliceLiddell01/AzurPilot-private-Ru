# Боевой выход

Раздел **«Боевой выход»** отвечает за основную кампанию и специальные сценарии фарма.

## Основная кампания

AzurPilotRu предоставляет три независимых task slot:

- **Основная кампания 1** — `Main`;
- **Основная кампания 2** — `Main2`;
- **Основная кампания 3** — `Main3`.

У каждого slot собственные:

- Scheduler;
- Campaign;
- StopCondition;
- Fleet;
- Submarine;
- Emotion;
- HpControl;
- EnemyPriority.

Это позволяет держать несколько разных конфигураций кампании и планировать их отдельно.

## Параметры Campaign

Текущий базовый шаблон использует:

```text
Name: 12-4
Mode: normal
UseClearMode: true
UseFleetLock: true
UseAutoSearch: true
```

Это не рекомендация фармить именно 12-4, а значение шаблона.

Перед запуском обязательно проверьте `Campaign.Name`.

## Сценарии фарма

Дополнительно доступны:

- **Срочные комиссии** (`GemsFarming`);
- **Экономичный флот за 3 нефти** (`ThreeOilLowCost`);
- **Засада 1-1** (`Ambush11`).

Русская локализация отдельно предупреждает про сценарий срочных комиссий: он может приносить небольшое количество драгоценных камней, но не считается эффективным способом прогресса аккаунта. Не воспринимайте его как универсальную рекомендуемую стратегию.

Сценарий «3 нефти» использует отдельную логику низкой стоимости и может автоматически заменять/отправлять в отставку флагман при достижении заданного уровня. Перед включением прочитайте его параметры особенно внимательно.

## Стоп-условия

Для campaign-задач доступны:

- лимит нефти;
- лимит монет;
- количество запусков;
- достижения карты;
- переход к следующему этапу;
- получение нового корабля;
- достижение уровня.

Подробнее: [Условия остановки](../usage/stop-conditions.md).

## Флоты

Перед автоматическим фармом проверьте:

- Fleet1;
- Fleet2;
- FleetOrder;
- формации;
- режим боя;
- подлодки;
- Emotion;
- HP-политику.

Подробнее: [Флоты и боевые настройки](../usage/fleets-and-combat.md).

## Безопасный первый запуск

Для новой campaign-конфигурации:

1. задайте небольшое `RunCount`;
2. оставьте запас нефти;
3. не включайте автоматическое продвижение по этапам;
4. наблюдайте первый проход;
5. проверьте, что используются нужные флоты;
6. только после этого увеличивайте длительность фарма.
