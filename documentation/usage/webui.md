# WebUI

WebUI — основной пользовательский интерфейс AzurPilotRu. Через него выбирается профиль, настраиваются задачи, устройство, планировщик и большинство игровых параметров.

После штатного запуска интерфейс по умолчанию доступен по адресу:

```text
http://127.0.0.1:25548/
```

Если используется `azur start --browser`, браузер открывается только после того, как Start подтвердит готовность WebUI.

## Как устроена навигация

Основное меню сгруппировано по назначению задач. В текущей документации используются упрощённые русские названия групп:

- **Порт** — общие настройки AzurPilotRu и вспомогательные операции;
- **Боевой выход** — основная кампания и фарм;
- **События** — событийные карты и режимы;
- **Автосбор наград** — комиссии, исследования, общежитие, гильдия и другие регулярные действия;
- **Ежедневные задания** — Daily, Hard, Exercise, магазины, постройка и другие периодические задачи;
- **Операция «Сирена»** — задачи OpSi;
- **План острова** — островные активности;
- **Инструменты** — дополнительные функции.

В самом текущем WebUI некоторые из этих пунктов ещё содержат исторический суффикс `+` или старое имя «Умный порт+». Документация намеренно использует более простые пользовательские названия, поскольку WebUI планируется перерабатывать.

## Профиль

Профиль — отдельный набор пользовательских настроек AzurPilotRu. Обычные профили представлены root-level JSON-файлами в каталоге `config/`.

При обнаружении профилей AzurPilotRu проверяет не только расширение файла, но и его структуру. В частности, обычный профиль должен содержать:

- секцию `Alas`;
- настройки `Alas.Emulator`;
- секцию `General`;
- хотя бы одну группу `Scheduler`.

Файлы шаблонов, неподдерживаемые JSON-файлы, небезопасные ссылки и неоднозначные имена не должны считаться реальными профилями.

Для пользователя отсюда следует простое правило: **не создавайте профиль копированием случайного JSON в `config/`**. Используйте штатные операции WebUI или корректный экспорт/импорт профиля.

Подробнее: [Профили и конфигурация](profiles-and-configuration.md).

## Настройки задач

Каждая задача состоит из групп параметров. Типичные группы:

- `Scheduler` — включение и время следующего запуска;
- `Emulator` — устройство и методы взаимодействия;
- `StopCondition` — ограничения выполнения;
- `Fleet` и `Submarine` — выбор флотов;
- `Emotion` — контроль настроения;
- дополнительные параметры конкретной задачи.

Не все группы присутствуют у каждой задачи.

## Что означает сохранение настройки

Изменение значения в WebUI меняет конфигурацию выбранного профиля. Оно не обязательно означает, что активная задача мгновенно прервётся и применит новое значение в середине действия.

Для времени выполнения важны два состояния:

- сохранённая конфигурация;
- уже запущенная runtime-задача.

Если изменение критично для безопасности — например, выбран не тот флот, устройство или лимит нефти — остановите текущую работу штатным способом и только затем продолжайте.

## Состояние выполнения

WebUI различает текущую выполняемую работу и будущие планы планировщика. Поэтому «следующая задача» или `NextRun` не являются доказательством того, что текущая runtime-задача уже завершилась.

При диагностике смотрите одновременно на:

- текущую активную задачу;
- очередь/планировщик;
- время `NextRun`;
- сообщения и журнал выполнения.

## Если интерфейс не открывается

Если `http://127.0.0.1:25548/` недоступен:

1. не запускайте несколько копий вручную;
2. выполните `azur doctor`;
3. повторно проверьте состояние через `azur start`;
4. если порт занят чужим процессом, не завершайте его наугад;
5. используйте раздел [Решение проблем](../maintenance/troubleshooting.md).

Далее: [Планировщик](scheduler.md).
