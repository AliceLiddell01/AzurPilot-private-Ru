# Флоты и боевые настройки

Боевые задачи AzurPilotRu используют не только выбранную карту, но и набор параметров флотов, подлодок, настроения, HP и приоритетов противников.

Перед длительным фармом важно понимать эти настройки: ошибка здесь может привести не просто к остановке задачи, а к нежелательным боям или расходу игровых ресурсов.

## Основные флоты

Группа `Fleet` позволяет выбрать игровые флоты для автоматизации.

Текущие базовые параметры:

- `Fleet1` — номер первого флота, от 1 до 6;
- `Fleet2` — второй флот; значение `0` отключает его использование;
- `Fleet1Formation` / `Fleet2Formation` — формация;
- `Fleet1Mode` / `Fleet2Mode` — режим боя;
- `FleetOrder` — распределение ролей между первым и вторым флотом.

Типичное значение `FleetOrder`:

```text
fleet1_mob_fleet2_boss
```

То есть первый флот используется против обычных противников, второй — для босса.

Поддерживаются и обратные/одиночные варианты, когда один флот выполняет всю карту, а другой остаётся в резерве.

## Формация и режим боя

Поддерживаемые формации:

- `line_ahead`;
- `double_line`;
- `diamond`.

Боевой режим может быть автоматическим, ручным либо специализированным режимом позиционирования. Для обычной автоматизации не меняйте эти значения только ради эксперимента: некоторые кампании и события предполагают конкретный способ боя.

## Подлодки

Группа `Submarine` управляет использованием подводного флота.

Основные параметры:

- номер подводного флота;
- режим применения;
- поведение в auto-search;
- расстояние вызова относительно босса.

Режимы включают отказ от подлодок, использование только на охоте, только на боссе, в обоих случаях или в каждом бою.

Если не уверены, оставьте `do_not_use`: вызов подлодок может расходовать дополнительные игровые ресурсы.

## Настроение

Группа `Emotion` позволяет AzurPilotRu учитывать настроение кораблей.

Для каждого флота есть:

- текущее расчётное значение;
- время последней записи;
- порог поведения;
- способ восстановления;
- признаки клятвы и горячего источника.

Режим `calculate` включает расчёт настроения. Значения вроде `prevent_green_face`, `prevent_yellow_face` и `prevent_red_face` определяют, насколько рано автоматизация должна избегать продолжения боя.

Если вы не понимаете механику morale в Azur Lane, не отключайте её контроль ради ускорения фарма.

## Контроль HP

Группа `HpControl` содержит отдельные механизмы:

- балансировка HP;
- использование аварийного ремонта;
- отступление при низком HP;
- пороги для этих решений.

По умолчанию дополнительные HP-механизмы могут быть выключены, поэтому не следует предполагать, что AzurPilotRu автоматически спасёт любой неправильно настроенный флот.

## Приоритет противников

`EnemyPriority` влияет на выбор целей на карте. Это уже не общая настройка устройства, а часть стратегии прохождения.

Меняйте её только если понимаете конкретную карту и причину изменения.

## Практика безопасной настройки

Перед первым длительным боевым запуском:

1. откройте нужную задачу кампании;
2. проверьте номер карты;
3. проверьте `Fleet1` и `Fleet2`;
4. проверьте роль каждого флота;
5. проверьте подлодки;
6. проверьте настроение и HP;
7. задайте [Условия остановки](stop-conditions.md);
8. выполните короткий наблюдаемый запуск.

Не используйте чужой профиль для боя без повторной проверки этих параметров.

Далее: [Условия остановки](stop-conditions.md).
