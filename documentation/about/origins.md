# Происхождение проекта

AzurPilotRu — персональная русскоязычная ветка более длинной экосистемы автоматизации Azur Lane.

Упрощённая линия происхождения:

```text
AzurLaneAutoScript
        ↓
     AzurPilot
        ↓
AzurPilot Private RU
```

## AzurLaneAutoScript

Историческая база проекта — AzurLaneAutoScript (ALAS).

Из-за этого имя `Alas` до сих пор встречается в конфигурации, Python symbols, логах и исторических названиях компонентов. Это не означает, что пользователю нужно устанавливать отдельный ALAS рядом с AzurPilotRu.

## AzurPilot

Непосредственный upstream персонального форка — `wess09/AzurPilot`. Он, в свою очередь, основан на `LmeSzinc/AzurLaneAutoScript`.

## Персональная ветка

Репозиторий `AliceLiddell01/AzurPilot-private-Ru` содержит отдельный эксплуатационный контур и намеренные изменения относительно upstream.

Стабильная пользовательская ветка — `personal/stable`. Ветка `master` намеренно сохраняется чистым зеркалом upstream и не предназначена для персональных fork-only изменений.

## Upstream не переносится автоматически

Новые изменения из `wess09/AzurPilot` не вливаются в `personal/stable` автоматически. Их нужно изучить, адаптировать к персональным отличиям, проверить тестами и оформить отдельным изменением.

Это позволяет не вернуть случайно удалённую телеметрию, старую модель обновления или несовместимое runtime behavior.

Подробнее: [Отличия AzurPilotRu](differences.md).
