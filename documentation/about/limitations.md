# Ограничения проекта

AzurPilotRu активно развивается и не является полностью завершённым пользовательским продуктом без ограничений.

Ниже перечислены ограничения, подтверждённые текущим проектом.

## Только Global/EN

CN, JP и TW не поддерживаются текущим runtime.

Подробнее: [Поддерживаемая версия игры](supported-game.md).

## Нет установщика в один клик

Новый пользователь пока получает repository и выполняет bootstrap через Git и uv. Полноценный desktop installer отсутствует.

## Нет завершённого release pipeline

Проект использует стабильную ветку `personal/stable` и controlled Update, но отдельный полноценный пользовательский release pipeline пока не реализован.

## Нет нового desktop shell

Отдельный современный desktop shell с tray, desktop notifications и autostart пока не реализован. Основной интерфейс остаётся WebUI.

## Не все старые игровые функции одинаково зрелые

Некоторые inherited задачи имеют прямые предупреждения в текущей локализации. Например:

- War Archives давно не обновлялся и может работать некорректно;
- Game Manager отмечен как «не завершено»;
- AutoEquip не имеет готовой полноценной стратегии экипировки;
- Opsi Simulator описан как alpha/beta аналитическая функция;
- отдельные Island tasks требуют `minitouch` и/или подготовленных assets.

Существование пункта в меню не означает одинаковый уровень поддержки.

## Автоматизация зависит от UI игры

После обновления Azur Lane могут измениться layout, buttons, event screens, OCR text и timings. Поэтому новая версия игры может временно нарушить конкретный workflow даже при исправном lifecycle AzurPilotRu.

## Нет автоматического удаления внешней инфраструктуры

Проект не удаляет самостоятельно внешние Cloudflare, ESA, 123pan, SSH и другие ресурсы, которые пользователь мог настроить вне repository.

Удаление такой инфраструктуры требует действий у соответствующего provider.

## Live acceptance ограничен безопасностью

Автоматические проверки не должны ради теста совершать покупки, расходовать игровые ресурсы без необходимости, выполнять необратимые действия или разрушительно завершать выбранный emulator без явного разрешения.

Поэтому часть реального gameplay behavior требует отдельной контролируемой acceptance.

## Автоматизация не гарантирует игровой результат

Даже корректно работающий task не гарантирует нужный drop, победу слабого флота, получение конкретного корабля или отсутствие изменений со стороны game server.

AzurPilotRu автоматизирует поддерживаемые действия, а не меняет вероятности и правила Azur Lane.
