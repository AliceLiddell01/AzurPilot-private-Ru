## Историческая база

Большой объём game automation, recognition и scheduler architecture происходит из AzurLaneAutoScript и связанных форков.

Поэтому исторические имена и комментарии из разных этапов экосистемы ещё встречаются в кодовой базе.

## Персональные изменения

AzurPilotRu добавляет собственный слой русификации, lifecycle/update/repair tooling, privacy изменений, Global/EN product boundary, storage/observability, MCP и дополнительной диагностики.

## Использование ИИ

README проекта прямо отмечает, что часть кода исходного проекта и персональных изменений создавалась или изменялась с помощью ИИ.

Такие изменения не считаются корректными только по факту генерации и должны проверяться тестами, CI, review, ручным анализом и live acceptance там, где она необходима.
