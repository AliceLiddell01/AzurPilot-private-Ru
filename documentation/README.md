# AzurPilotRu

AzurPilotRu — русскоязычная персональная версия AzurPilot для автоматизации **Azur Lane Global**. Программа подключается к Android-эмулятору или устройству, распознаёт интерфейс игры и выполняет настроенные пользователем задачи: ежедневные активности, комиссии, исследования, кампанию, события, Операцию «Сирена» и другие поддерживаемые сценарии.

Эта документация рассчитана прежде всего на человека, который **впервые видит проект**. Для установки и обычного использования не требуется разбираться в исходном коде.

> **Важно:** текущая игровая граница AzurPilotRu — только **Global/EN**: сервер `en` и пакет Android `com.YoStarEN.AzurLane`. Версии игры других регионов не являются поддерживаемым runtime.

## Основные особенности AzurPilotRu

### Русский интерфейс

Активный WebUI работает с локализацией `ru-RU`. Навигация, настройки, задачи, сообщения и большая часть first-party пользовательского интерфейса переведены на русский язык. Технические идентификаторы, пути, команды и оригинальные названия внешних сущностей сохраняются там, где перевод мог бы изменить смысл.

### Контролируемый запуск и обслуживание

Основной пользовательский интерфейс командной строки — команда `azur`:

```text
azur doctor
azur build
azur start
azur stop
azur repair
azur update
```

Запуск, обновление и восстановление разделены: обычный `azur start` не выполняет скрытое обновление Git, а `azur update` является отдельной явной операцией.

### WebUI

После успешного запуска локальный интерфейс по умолчанию доступен по адресу:

```text
http://127.0.0.1:25548/
```

Порт можно изменить в конфигурации, но документация исходит из стандартного значения `25548`, если не указано обратное.

### Приватность и сетевое поведение

Из персональной версии удалена часть унаследованных механизмов автоматической телеметрии и project-controlled сетевого поведения. При этом сторонние интеграции, которые пользователь включает самостоятельно — например, уведомления, MCP, LLM, прокси или удалённый доступ, — могут обращаться к выбранным внешним сервисам.

Подробнее: [Приватность и сетевое поведение](architecture/privacy-network.md).
